# holbertonschool-shell
Shell, basics

Permissions Project

This project covers Linux file permissions and basic user management in Ubuntu 22.04 LTS.

We learn how to use commands like chmod, chown, chgrp, su, and sudo to manage users, groups, and file permissions.

Each script follows strict rules: exactly 2 lines, starts with #!/bin/bash, is executable, and does not use backticks, &&, ||, or ;.

The goal is to understand how Linux controls access to files and users through permissions.
